# Developer Productivity Dashboard

A modern and responsive **Developer Productivity Dashboard** built using React.js and Vite. This project was developed as part of the **Full Stack Development Internship – Task 1**.

## Project Overview

The Developer Productivity Dashboard provides a simple interface for developers to view their projects, tasks, progress, and productivity information.

The dashboard includes reusable project cards, project search functionality, progress indicators, and responsive design for different screen sizes.

## Features

*  Dashboard overview
*  Navigation bar
*  User profile section
*  Project cards
*  Project progress indicators
*  Project search functionality
*  Empty state when no project matches the search
*  Loading state
*  Error state
*  Responsive design for mobile and desktop screens
*  Reusable React components

## Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Vite
* Node.js

##  How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd task1_internship
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal to view the dashboard.

## Search Functionality

The dashboard allows users to search for projects by project name.

For example:

* `AI` → AI Dashboard
* `Task` → Task Manager
* `Portfolio` → Portfolio Website
* An unmatched search → "No projects found"
